# SPARTAN QUEST / READER

英文を前から、意味のまとまりごとに読む練習アプリ。React + Viteの静的サイトです。
初期表示はポップな「クエスト」。トップ画面の「クラシック表示に切り替える」から従来の画面と読書操作に戻せます。切り替えは同じ端末に保存されます。変更前のソースはGitHubの`classic-2026-09-27`ブランチにも保管しています。

## クエストモード

ひとつの英文を一つの冒険として表示し、小さな読解ロボが進行マップを進みます。長い英文には最大3つのチェックポイントがあり、一時停止して先へ進むか少し戻るかを選べます。チェックポイントは文末を優先して配置しますが、段落を推定したものではありません。短い英文ではチェックポイントを作りません。

全表示範囲を次へ進めたうえで末尾へ到達すると、初回だけ「きらめき」を30個獲得します。復習リストから最後へ飛ぶだけでは獲得できません。これは表示範囲を進めた操作の記録で、読んだ時間や理解度を測定・採点するものではありません。記録はLocalStorageに保存し、端末間の同期はありません。読了IDは通常の最近履歴とは別に保持し、500件を超えても削除しません。既存のv1形式を引き続き読み込みますが、旧版で既に削除されたIDの復元はできません。破損した既存記録は上書きせず、保存に失敗した場合も読書は続けられます。

キャラと画面の絵はアプリ内のSVGとCSSです。日本語の丸ゴシックは同梱したM PLUS Rounded 1cを利用し、外部フォント配信には依存しません。

## 使い方

英文の直接入力は、端末内の簡易ルールで分割するだけで、自動翻訳はしません。
和訳付きで読む場合は「プロンプトコピー」で外部AIにJSONを生成させ、貼り付けます。生徒の個人情報などは外部AIへ送らないでください。
「校閲済みサンプルを入れる」で、提供された全文を32チャンクに整理した教材を試せます。

`en`は必須、`jp`と`speaker`は省略可能です。従来の文字列配列にも対応します。不正な項目は黙って削除せず、入力全体をエラーにします。
一般的なスマートクォート、完全なコードフェンス、対応する外側のかぎ括弧は補正します。すべての壊れたJSONを復元できるわけではありません。

## プロンプト・教材

- コピー用プロンプト v3.0：`services/chunkPrompt.ts`
- 校閲済み全文：`public/libraries-of-things.reviewed.json`
- 原文・問題があった入力：`tests/fixtures/`

基本2〜7語、構文を保つ必要がある場合は最大12語を許容し、画面で自然に折り返します。各画面のenとjpが同じ範囲を指すことを優先し、訳の移動・先取りを避けます。
校閲済み32チャンクは228語の原文を欠落・変更なく保持しています。ただし、原文復元やJSON構文の検査だけでは日本語訳の質は保証できません。新しいAI出力には校閲が必要です。
端末内の自動分割は構文解析ではなく簡易ルールです。12語は目安として、冠詞・前置詞・助動詞の直後を避けます。「分割プレビュー・調整」で、通常の英文は改行位置、訳付き教材はJSONのen・jp・speakerを確認・調整できます。適用すると入力欄にJSONとして反映されます。

## 操作と保存

WPM 70〜160、訳ON/OFFと2〜7秒遅延、1〜5語またはチャンク表示、4種のアニメーション、復習リスト、前後移動に対応。
遅延は再生中だけ進み、訳OFFや訳のない箇所に待ち時間は加えません。単語表示中の和訳は元チャンク全体の訳であることを明示します。
入力途中の下書きと学習設定（速度・訳表示・遅延・表示単位・アニメーション）はこの端末に自動保存されます。「前回の続きから読む」で最後に開いていた教材の単語位置から一時停止状態で再開します。再開は編集中の別の下書きを上書きしません。クエストの確認済み範囲は表示単位を変えても保持します。
設定画面の「学習設定をリセット」は設定だけを初期値へ戻し、下書き・教材・履歴・読了報酬は保持します。保存データが壊れている場合や容量不足の場合は警告し、元データを保護します。
履歴はLocalStorageに保存し、端末間同期はありません。通常15件とは別にお気に入りを保持します。容量不足は警告し、壊れた既存履歴は上書きしません。

## 検査

```
npm ci
npm run check
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

GitHub Actionsで厳密な型検査、単体検査、本番ビルド、依存関係監査、3環境のブラウザ検査を実行します。新旧両モード、チェックポイント、初回報酬、スマホ表示に加え、下書き復元・中断再開・学習設定の保存とリセット・分割プレビュー・末尾への飛び越しを含みます。`SPARTAN_TEST_PORT`で専用ポートを指定でき、別の既存サーバーを再利用しません。
外部通信を遮断した状態でアプリを検査します。HTMLレポート・スクリーンショット・失敗時トレース・distをArtifactsに保存します。
このCIはLLM APIを呼びません。コピーされる指示文と既存教材の動作は検査しますが、将来のAI生成結果すべての翻訳品質は保証しません。

`wrangler.toml`はPages用です。Cloudflare側のプロジェクト作成・Git連携は別途必要です。CI成功やdist生成だけでは公開済みになりません。
公開後の`/build-info.json`にあるcommitで、配信中のコードとGitHubを照合できます。
公式資料：https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/

アプリはAI APIへ自動送信せず、CSSも外部CDNに依存しません。付属教材はユーザー提供文の校閲例であり、特定の図書館の出来事を検証した資料ではありません。
