# 雑学サンプルと自分の英文

ポップ版の入力画面には、二つの入口があります。

## サンプルを試す

1. 雑学を選び、英文と和訳のプレビューを見る。
2. 「サンプルJSONをコピー」を押す。
3. 「入力欄へ」から共通の「英文テキスト」に貼り付ける。
4. 「冒険をはじめる」を押す。読書画面で「日本語訳」をONにすると和訳が表示される。

選択・コピーだけでは入力、下書き、読書位置、設定を変更しない。クリップボードが使えない場合は、表示されたJSONを手動で選択・コピーできる。表示単位や訳の遅延など、保存済みの学習設定は読書時に引き継ぐ。

## 自分の英文で作る

「自分の英文で作る」を選び、共通入力欄へ英文を貼り付けて「プロンプトコピー」を押す。利用中の外部AIへ手動で貼り付け、生成されたJSONを確認して入力欄へ貼り戻す。アプリから自動でAIへ送信したり、APIを呼んだりする機能はない。英文だけの読書も従来どおり利用できる。

プロンプト3.1は、原文の復元、英文と和訳の範囲一致、否定・条件などの保持、JSON構文を明示する。語数は目安であり、意味を壊して12語以内へ切り詰めない。プロンプトの検査は将来のAI出力の正確性を保証しないため、生成された教材は確認する。

## 教材と出典

10本、合計1,023語・139チャンク。提供された最終校閲版のチャンクを変更せず収録。

- `public/trivia-samples.json`: 画面表示用の題名・紹介・出典と各チャンク。
- `public/samples/*.json`: 読み込み可能なJSON配列のみ。提供された個別JSONと同一。
- `source-ledger.md`: 事実の範囲と一次資料。
- `editorial-review.md` / `independent-review.md`: 英文・和訳・意味範囲のレビュー。
- `validation-report.json`: 提供教材の機械的検査記録。

元教材パック: `SPARTAN-QUEST-trivia-pack-01.zip`、SHA256 `18e82950712adbac9048cce5edb15da7b1f812e9a81a1e6d7d25be0623a23f4f`。
出典は各サンプルの「この雑学の参考資料」からも開ける。出典の文章の転載ではなく、独自の短い英文と対応和訳である。

`npm run check` と `npm run test:e2e` で、全教材のパーサー往復、原文復元、コピー・貼付、全英日チャンク表示、コピー失敗時の手動導線、モバイル／デスクトップと既存機能の回帰を検証する。
